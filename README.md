# Spotify Glass — текст песни (виджет Rainmeter)

Локальный мост: Spotify → текст с синхронизацией (Spicy Lyrics / LRCLIB) →
PNG с подсветкой слова → маленький виджет **LyricsGlass** в Rainmeter.

## Запуск

1. Двойной клик по `run.bat` (или `pythonw bridge.py`)
2. Виджет LyricsGlass уже активен в Rainmeter — просто включи песню в Spotify

Окно браузера больше не нужно; при желании: `python bridge.py --window`.

## Что нужно

- Spotify desktop (запущен)
- Python 3.11 + `pip install winsdk requests pillow`
- Rainmeter + скин `Documents\Rainmeter\Skins\LyricsGlass\`

## Настройки (`config.json`)

| Ключ | Что делает |
|---|---|
| `spicy_key` | ключ Spicy Lyrics (`sl_sk_...`) — пословная синхронизация |
| `port` | порт локального HTTP (для `--window`) |
| `widget_width` | ширина виджета в пикселях (по умолчанию 390) |
| `widget_png` | куда писать картинку (по умолчанию `@Resources\lyrics.png` скина) |
| `lag_offset_ms` | сдвиг подсветки от звука, мс: `+` раньше звука, `−` позже (по умолчанию 0) |

Источник текста выбирается автоматически: синхронизированный текст лучше
статичного — сперва Spicy Lyrics, если там нет таймингов, пробуется LRCLIB.

## Как это работает

| Файл | Что делает |
|---|---|
| `bridge.py` | SMTC (позиция Spotify) → API текста → рисует PNG ~33 кадрам/сек |
| `LyricsGlass.ini` | скин-виджет: Image-метр показывает кадр, `frame.lua` переключает файлы |
| `static/index.html` | старое HTML-окно (опция `--window`) |
| `cache/` | кэш текстов по трекам |

### Почему два файла кадров (анти-мерцание)

Rainmeter каждое обновление перечитывает PNG; если заменить файл в момент их
открытия, метр обнуляется до 1×1 — виджет мигает. Поэтому кадры пишутся
через пинг-понг: мост пишет всегда только **не показываемый** файл
(`lyrics_a.png` ↔ `lyrics_b.png`), затем кладёт букву в `frame.txt`;
`@Resources\frame.lua` меняет `ImageName` и подтверждает показ в `ack.txt` —
следующий кадр пишется только после подтверждения. Старый `lyrics.png` больше
не используется (остался для совместимости).

Окно виджета мост держит на рабочем столе: выше обоев, ниже обычных окон.
Позицию можно перетаскивать — после перетаскивания мост её не трогает.

## Синхронизация и подсветка

- точная пословная (Spicy, `Type=Syllable`) — подсветка слова идёт по таймингу
- оценочная (LRCLIB / `Type=Line`) — слова распределены по длине внутри строки
- без таймингов — показывается первая строка, плавных переходов нет

Текущее слово: чистый белый + bloom (размытый ореол), яркость соседних
слов перетекает плавно (250 мс), свечение слова — синусоидальный импульс.

## Режимы

```
python bridge.py            # обычный (виджет + HTTP)
python bridge.py --demo     # демо-трек без Spotify
python bridge.py --window   # + HTML-окно в браузере
```

## Атрибуция

Spicy Lyrics по условиям использования требует указывать источник текста.
Сейчас строка атрибуции в виджете отключена по вашему запросу. Если провайдер
потребует её вернуть — это один блок в `build_widget_image` (`_credit_text`).
