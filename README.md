# Spotify Glass — текст песни (виджет Rainmeter)

Локальный мост: **Spotify → текст с синхронизацией (Spicy Lyrics / LRCLIB) → PNG с подсветкой слова → виджет LyricsGlass в Rainmeter.**

Виджет работает прямо на рабочем столе, ниже открытых окон, обновляется ~33 кадра/с, подсветка плывёт по словам синхронно со звуком.

---

## 🚀 Быстрый старт

### 1. Установи зависимости

```powershell
pip install winsdk requests pillow
```

Нужен **Python 3.11** (или новее). Rainmeter должен быть установлен и запущен.

### 2. Настрой конфиг

Скопируй шаблон:

```powershell
copy config.example.json config.json
```

Открой `config.json` и вставь свой ключ Spicy Lyrics:

```json
{
  "spicy_key": "sl_sk_твой_ключ_здесь",
  "port": 8765,
  "widget_width": 390,
  "lag_offset_ms": 0
}
```

- `spicy_key` — ключ из [Spicy Lyrics](https://spicyyrics.com) (бесплатный, регистрация на сайте).
- `lag_offset_ms` — сдвиг подсветки относительно звука, мс. `+` = текст раньше звука, `−` = текст позже. По умолчанию `0`.

### 3. Запусти мост

```powershell
run.bat
```

Или вручную:

```powershell
pythonw bridge.py
```

### 4. Включи песню в Spotify

Виджет **LyricsGlass** в Rainmeter покажет текст с подсветкой текущего слова. Позицию виджета можно перетаскивать мышкой — мост её не сбросит.

## 📦 Что в репозитории

| Файл | Что делает |

| `bridge.py` | Мост: SMTC (позиция Spotify) → API текста → рисует PNG ~33 кадра/с |

| `run.bat` | Лаунчер моста (`pythonw bridge.py`) |
| `.gitignore` | Исключает кэш, логи, отрисованные кадры |
| `static/index.html` | Старое HTML-окно (опция `--window`) |

## 🛠 Настройка Rainmeter

Скин `LyricsGlass` должен лежать в:

```
Documents\Rainmeter\Skins\LyricsGlass\LyricsGlass.ini
```

В скине уже прописано:
- `Update=16` — 60 Гц перерисовка
- `DynamicVariables=1` — перечитывание PNG при каждом кадре
- `Measure=Script` + `@Resources\frame.lua` — пинг-понг кадров (анти-мерцание)

Если виджет не появился — обнови скин через Rainmeter: `!Refresh "LyricsGlass"`.

---

## ⚙️ Настройка синхронизации

Если подсветка опережает или отстаёт от звука, крути `lag_offset_ms` в `config.json`:

- Видео/текст **опережает** звук → уменьшай `lag_offset_ms` (например, `-50`)
- Видео/текст **отстаёт** от звука → увеличивай `lag_offset_ms` (например, `+50`)

После изменения перезапусти мост (`run.bat`).

```
python bridge.py            # обычный (виджет + HTTP API)

python bridge.py --window   # + HTML-окно в браузере для отладки
```

## 🔒 Анти-мерцание

Два файла кадров (`lyrics_a.png` / `lyrics_b.png`) пишутся по очереди. Мост пишет только в файл, который Rainmeter **не показывает** в данный момент. Скрипт `frame.lua` переключает `ImageName` и подтверждает показ в `ack.txt` — следующий кадр пишется только после подтверждения. Читатель и писатель никогда не работают с одним файлом одновременно, поэтому виджет не мигает.

---

## 📄 Атрибуция

Spicy Lyrics по условиям использования требует указывать источник текста. Строка атрибуции в виджете отключена по запросу пользователя. Если провайдер потребует её вернуть — это один блок в `build_widget_image` (`_credit_text`).

---

## 🐛 Если что-то не работает

| Симптом | Решение |
|---|---|
| Виджет пуст | Проверь, что Spotify играет и `spicy_key` верный |
| Текст отстаёт от звука | Измени `lag_offset_ms` в `config.json` |
| Виджет мигает | Убедись, что в Rainmeter скин обновлён (`!Refresh "LyricsGlass"`) |
| Ошибка в логе | `Rainmeter.log` в `%APPDATA%\Rainmeter\` |
